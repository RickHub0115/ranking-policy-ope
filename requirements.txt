# Fully pinned environment for the experiments.

# Python: 3.9.x REQUIRED (obp 0.5.x declares python >=3.7.1,<3.10).
#
# obp is pinned to 0.5.5: its four slate modules (dataset/synthetic_slate.py,
# ope/{estimators_slate,meta_slate,regression_model_slate}.py) are byte-identical
# to zr-obp master commit 8cbd5fa (2022-11-04), which the upstream line
# references in the source comments refer to. (obp==0.5.2, the pin of the
# AIPS reference implementation, has the same python<3.10 constraint.)
#
# macOS arm64 note: PyYAML 5.4.1 has no arm64 wheel and its sdist fails to
# build under Cython>=3. Pre-install it with a build constraint first:
#   echo "cython<3" > /tmp/c.txt
#   PIP_CONSTRAINT=/tmp/c.txt pip install pyyaml==5.4.1
# On Linux x86_64 manylinux wheels exist and
# `pip install -r requirements.txt` works directly.
